# 果蝇交易员接入约定

用户确认范围：完整果蝇神经运行、3D 家园、交流、学习和交易统计；首版支持 Windows，面向独立安装 QuantStudio 的用户。源码来自 `songshuquant/ssquant-fly-agent` 的 `codex/fly-autonomous-v2`。

交易复用 PandaAI 比赛 CLI，行情复用 PandaData。首版生成冻结计划，由用户在现有比赛确认卡逐笔执行。赛事端尚未定义持续授权协议，不提供无人确认执行。果蝇与 Jev 盯盘为独立策略，账户存在未完成计划或委托时不追加计划。

Python 神经与生活运行在独立进程。宿主仅开放账户查询、行情、模型调用和预演接口；神经进程不持有账户凭据或执行接口。模块文件随应用分发，首次使用将运行环境下载到用户目录并校验。语言模型复用已验证的 QuantStudio 配置。

关闭页面不停止后台生活；退出 Host 停止进程并保存。重启恢复记忆与家园，交易建议默认停止，需重新核对账户并启动。模型与造景分别计数、限制调用，不虚构服务商费用。

验收：专用环境准备、真实模块启动、3D 资产加载、状态保存恢复；账户切换、过期行情、重复计划与成交反馈隔离；相关 Python/TypeScript 测试、宿主与客户端构建。交易连接和成交验证需区分模拟接口测试与真实柜台结果。

## 使用

1. 重启构建后的 QuantStudio，从「比赛」页果蝇卡片的「准备果蝇交易员」或侧栏进入果蝇页面，在首次设置中点击「一键准备果蝇」。控制器与神经 Python、MaleCNS 依次在后台准备，页面切换不打断准备；进度、错误和重试可见。已有 Blender 时可填写安装目录或 `blender.exe` 路径，验证后复用；也会自动识别 PATH 中的 Blender，未找到时准备专用版本。
2. 模型连接与 Jev API Key 统一在「设置 → 模型服务」管理。Jev 区域测试成功后保存到原有凭据库，比赛盯盘与果蝇共用，密钥不回显；已有密钥无需迁移。两处使用入口均提示配置路径并提供跳转。果蝇列表直接读取用户在 QuantStudio 接入并验证成功的模型，调用复用原有连接与密钥；语言 AI、Jev 和造景调用额度默认为 0，先设置额度再测试连接。只体验神经生活不需要模型 API。
3. 在果蝇「行情配置 → 额度」点击「连接比赛账户」，无需先填写合约，也可复用「比赛」页已连接的账户。连接成功后，已勾选品种会自动查询主力；其他月份下拉选择后核对，已有手工选择保留。首次「进入家园」或后续「保存配置」会保存设置，不自动连接行情；在看板单独点击「连接比赛行情」。成功后显示连接状态和最近同步时间，不再展示重复连接按钮。暂时失败按冷却时间自动恢复；授权失效或账户变化时停止自动重试并提示重新连接。需要交易建议时，在设置中连接 PandaData，填写名义金额、总占用和损失上限，关闭「仅验证生活」。
4. 对应合约的 500 根完整 K 线和新鲜报价就绪后，在果蝇页面启动交易建议。比赛页 Jev 与果蝇卡片默认折叠；果蝇摘要显示运行状态、待确认计划数、当日确认成交数和已实现毛盈亏，展开后查看行情准备情况、比赛账户持仓和最近成交。卡片每 3 秒读取同一果蝇后台，折叠时仍更新。账户不匹配时不展示旧账户交易数据；安装、配置和交易建议控制统一在果蝇页面办理，每笔计划仍需逐笔确认。

历史首次补齐 500 根已完成 K 线，之后复用持久化窗口，按原生 1 或 5 分钟周期从最早缺口或窗口尾部所属交易日期补取，休市时改为每 5 分钟检查。PandaData 接口按交易日期查询，因此最新交易日会有重叠，按时间戳合并去重；不再每轮重取整个初始日期窗口。重启后复用缓存，长期离线导致窗口过旧时重新补齐。果蝇看板与比赛卡片展开区的「获取历史数据」按钮共用同一后台任务，立即返回状态，不阻塞家园。每个合约显示已完成 K 线根数、来源最近成功时间及失败原因，切换合约或周期时不写入旧请求结果。成功获取不等于可交易，仍需通过 500 根完整性及新鲜报价检查。

历史和比赛连接各自持久化冷却状态，手动按钮、自动刷新和页面切换不能绕过。页面区分「比赛接口」和「PandaData」故障，显示重试倒计时；有服务端等待时间时遵守该时间，否则按 30、60、120、240、300 秒退避。限流或授权失效会终止本轮剩余合约请求；其他单合约失败继续处理其他合约，已有缓存与成功时间保留。行情轮询复用 15 秒账户快照，只读同步保留账户身份检查，不再反复执行完整 doctor 自检；交易预演和执行仍使用原有完整校验。

交易决策使用 PandaData 原生 1 或 5 分钟线；3 分钟只用于分析图表的显示聚合，不作为行情请求。合约不自动换月。存在待处理计划或委托时等待；Jev 盯盘运行时不生成果蝇计划。停止建议不撤销已提交委托。

历史行情通过 PandaData MCP 的 `get_future_min` 获取。返回被截断的预览时，程序自动拆分交易日期区间，完整读取各段后统一写入缓存，再校验并取最新 500 根已完成 K 线；不把预览当作完整历史。单日仍被截断或任一分段失败时保留原缓存并报告错误，修复前不绕过历史完整性检查。

手续费、出入金、柜台交易日或完整成交证据缺失时，继续保存实际账户权益和已确认成交，暂停交易奖励结算；缺失数据不按零处理。学习仅发生在读出层，神经连接组冻结。事件回放读取本地记录，不提供旧宿主的历史回测引擎。

状态位于当前 DSH 用户目录下的 `quantskills/fly`。Host 退出等待检查点保存；再次打开恢复记忆与家园，但不会自动恢复交易建议。源码来源与分发说明见 `packages/quantskills-session/fly-runtime/PROVENANCE.md`。

## 验证命令

`node scripts/verify-fly-runtime.mjs` 在系统临时目录创建隔离控制器，验证资源和重启记忆。加 `--neural --scene` 会准备真实神经依赖、运行神经生活并用 Blender 构建和校验家园；可加 `--blender "安装目录"` 复用本机版本。测试不连接账户、不下单，也不调用付费模型。
