# PandaAI 比赛模式

本页说明：**「巅峰交易者」全国期货模拟赛**。侧栏「比赛」同时提供[第四届因子大赛](factor-contest.md)，两项比赛分别开关和连接。

比赛模式默认关闭。它使用独立的官方 CLI、授权目录和比赛研究会话；普通会话、PandaData 连接、模型配置和能力库沿用原有设置。

## 开始使用

1. 更新代码和依赖后正常重启 QuantStudio，在侧栏 **QUBE → EVO** 下方打开 **比赛**。
2. 开启 **比赛模式**，点击 **连接比赛**。首次连接会在应用数据目录内安装官方 CLI 和交易规则，然后打开 PandaAI 官网授权。
3. 如尚未报名，点击 **赛事报名**，在官网完成报名和身份信息填写。返回应用检查连接。
4. 连接成功后，可查看资金、持仓、当前挂单、委托、成交、排名、每日结算和单品种最新行情。委托、成交默认查询今天，可切换最近记录并翻页。
5. 点击 **进入 AI 交易助手**，默认继续当前赛事账户的主对话；首次进入才创建。**新建专题对话** 用于独立研究，**继续最近对话** 可恢复最近的主对话或专题。旧版未区分类型的会话按最早创建的一条作为默认入口，不改写历史。归档主对话后，下次进入会选择或建立可用主对话。
6. 输入框上方显示账户身份，并自动只读巡检资金、持仓、活动委托和待处理计划。可直接使用 **研究持仓**、**研究品种**、**今日复盘**，或输入自己的需求。**比赛工作台** 返回账户和模式设置。
7. 你选择具体方案后，AI 读取官方执行规范并生成预演。交易确认卡展示实际合约、方向、手数、价格、行情时间、账户和有效期。核对后点击 **确认执行这笔交易**。也可从输入框上方 **比赛计划** 或比赛工作台查看计划及回执。

首版支持 Windows 和 macOS 本机运行，只支持单笔开仓、平仓和撤单。比赛页面需要主机可以访问官方文档及 npm，并可在本机打开浏览器。比赛会话沿用已配置的模型，研究数据通过现有数据库的只读查询或当前会话附件提供。

## 比赛专用对话与隔离

| 层次 | 比赛专用行为 | 普通会话 |
| --- | --- | --- |
| 会话 | 固定赛事、账户和主对话/专题身份，恢复后仍保持绑定 | 保持原会话和历史 |
| 模型与运行框架 | 复用 DSH；只在比赛会话启用原生工具调用和严格工具范围 | 不修改模型、预设和全局工具设置 |
| 提示词 | 巡检、研究、执行准备、复盘分阶段；注入带时间的账户快照 | 不注入比赛提示词、账户快照或交易授权 |
| 常驻技能 | `contest-account-check`、`contest-research-plan`、`contest-daily-review` | 不注册这三项比赛技能 |
| 工具 | 比赛查询、巡检、记录、规范和预演；当前会话附件与缓存数据只读查询 | 维持原工具权限 |
| 执行 | 单笔计划由界面确认；模型没有执行工具 | 不继承比赛授权 |

比赛会话禁止 Shell、任意代码、直接 HTTP、其他交易通道与委派。工具范围和最终调用检查都设置在该会话的作用域内，后续加入的工具也不能绕过。缓存数据查询要求显式 `refresh=false`；需要补充历史行情或更新数据时，到数据库页准备。最新报价不能替代历史数据，缺少数据时应说明缺口。

账户事实每次研究或预演前重新读取。主对话保留用户在该对话确认的约束；专题对话只共享该账户的计划与回执，不自动复制其他会话的聊天记录、偏好或授权。切换账户后，旧比赛会话不能查询或操作新账户。进入会话的自动巡检仅展示只读摘要，不自动发起研究或交易。

## 开关与交易状态

- 随时可以关闭比赛模式，包括正在安装、登录或等待确认时。关闭会停止比赛调用，使尚未执行的计划失效；普通研究可以继续。
- **关闭比赛模式不会撤销已经提交的委托。** 这些委托继续由赛事柜台处理，可在官网查看，或重新开启并连接后查询。
- 再次开启后需要点击连接验证账户；之前的待确认计划不能继续执行。
- 计划过期或参数变化时需要重新预演。重复点击确认不会创建第二次提交。
- “已排队”“已提交”表示操作处理中；“操作已完成”也不等于全部成交，最终以委托和成交记录为准。
- 丢失回执或应用在提交时退出，计划会标为 **回执待核实**。只能查询柜台回执，不会自动重发。若官网仍无法核实，请先联系赛事支持确认。
- 页面对处理中操作进行有限次数的自动查询，随后可手动查询；不提供定时研究或自动下单。

## CLI、更新与数据位置

比赛页自动检查 CLI 更新，安装更新需要点击 **更新 CLI**。有待确认计划、未核实操作或活动委托时会暂缓更新。更新失败保留原运行版本，需要重新检查连接。

比赛数据位于 `<DSH_HOME>/quantskills/contest/`，默认 `DSH_HOME` 为 `~/.dsh`：

- `auth/`：官方 CLI 的独立授权资料，不复用用户全局 CLI 账户。
- `runtimes/<id>/`：独立 CLI 安装和官方交易规则。
- `state.json`：模式开关、账户绑定和计划回执记录。

不要把该目录作为项目文件提交或分享。界面和模型收到的结构化 CLI 响应会过滤凭据及个人身份字段。只有专用比赛会话注册查询、预演工具；执行入口是用户界面的确认操作。

官方资料：[CLI 接入指南](https://www.pandaaiquant.com/openapi/v1/agent-install-guide/cli) · [比赛与报名](https://www.pandaaiquant.com/contest/)

## 连接和页面等待恢复（2026-09-15）

期货赛与因子赛共用比赛范围内的状态读取逻辑：连接接口返回后立即显示结果，状态轮询等待上一次请求结束后再安排下一次。查询失败后再次读取成功会清除读取错误；用户操作失败的提示独立保留。

- 状态读取最多等待 15 秒；数据页和账户巡检最多等待 30 秒，超时后显示错误并恢复重试入口。
- 切换数据分类、退出比赛页面、切换会话或关闭模式会废弃旧响应，并将只读请求的取消信号传到 Host 和 CLI。检查连接时先取消后台数据读取，后台 CLI 版本检查也不再阻塞连接队列。
- 因子账户登录验证通过即返回，余额、报名状态与因子池在独立巡检中加载；普通数据读取不锁住连接和 AI 入口。
- 计划操作返回后立即展示回执、恢复弹窗交互，不等待第二次状态刷新。确认等待超过 60 秒可关闭弹窗并只读核对，原计划仍禁止重复提交。停止等待不代表柜台或平台已取消执行。
- AI 对话准备完成即进入；切走页面后到达的创建结果不会再跳转。普通会话继续使用原有提示词、技能和工具。

回归验证：新增 26 项用例，98 项比赛后端与界面测试、5 项专用会话入口测试均通过；会话及 Windows 后台进程复查共 45 项通过。Host、远程接口和界面类型检查、构建、源码完整性及独立环境启动通过。全库首次执行 713 项通过、5 个断言失败；修正巡检取消信号断言、同步主线依赖后，对应 2 项复查通过，剩余为此前记录的 3 个无关断言失败和 3 个缺少 mock-adapter 的文件无法收集。未重复执行全库，也未提交比赛交易、回测或参赛操作。


确认失败后的恢复：点击「只读核对确认结果」会等待此前确认请求退出后读取计划。只有后端确认计划仍未提交、状态为待确认时，才恢复取消和手动确认按钮；普通状态轮询不会解锁。超时、核对失败、执行中或未知回执继续禁止重复提交，不会自动重试交易、预算授权或参赛操作。
