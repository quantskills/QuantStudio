# 会话删除与归档

会话卡片和对话侧栏使用 `⋮` 菜单，提供归档与删除；单个和批量归档均需确认。设置 → 归档会话可搜索、恢复或删除普通、技能、专家和专家团会话。

- 归档只改变可见性，完整保留原会话 ID、上下文及记录。
- 恢复取消归档，不复制会话或创建新 ID。
- 会话删除先关闭空闲会话，再清除 JSONL 日志、子任务日志、投影缓存、搜索索引和工作区中的会话引用。独立分支会话、工作区文件以及已创建的技能、专家、专家团定义不被删除。
- 运行中的会话或子任务需要先停止。永久删除前的确认框明确说明无法恢复。
- 删除前写入恢复日志；完整删除同时记录已经确认的文件路径与指纹。中途失败时，下次启动完成剩余清理，防止日志已删除而索引仍存在。
- 旧版“删除”留下的归档记录继续保留，由用户选择恢复或永久删除。

## 完整删除与文件清单

删除弹窗默认聚焦主按钮「会话删除」，保留生成文件；「完整删除」作为次要入口，先调用 `deletionPreview` 展示具体文件和保留原因，明确告知会话及清单内文件删除后无法恢复，再由用户二次确认。二次确认默认聚焦「返回」，避免连续按键误删文件。预览不删除数据；15 分钟内有效的令牌绑定会话及文件版本，服务端在执行时重新核验文件清单、其他会话引用和文件指纹。文件变化后必须重新预览。

文件来源包括本会话及子任务成功 `write` 的新建记录，以及会话明确交付的 `output/` 文件。对于旧版脚本产物，仅接纳创建时间不早于会话开始的 `output/` 交付文件。继承的分支历史不作为新建证明；没有明确归属的文件保留，不按目录或修改时间批量清空。已有覆盖记录、输入附件、其他会话引用的产物、隐藏配置、符号链接及越界路径均保留。清理逐个核对常规文件并 unlink，不递归删除工作区，空目录保留。

真实文件测试使用临时工作区验证子任务产物清理、共享/已有文件保留、越界和 junction 拒绝、预览后文件变化拒绝、普通删除不清理文件，以及清理文件后的中断恢复。测试不会删除用户已有会话或产物。

## 固定版本运行时补丁

上游 DSH `0.1.2-alpha.2` 只提供归档，没有配套恢复和完整删除 API。本功能通过 `pnpm-workspace.yaml` 和锁文件中的五个补丁增加必要操作，补丁均保存在 `patches/`，不会依赖手动修改 `node_modules`：

1. `dsh-agent`：记录精确的生命周期句柄，阻止删除期间的新激活，按既有顺序关闭会话。
2. `dsh-session-persistence-jsonl`：等待写队列与退出流程完成后删除日志，清除冷读缓存；校验文件仍在持久化目录内。
3. `dsh-session-projection-cache`：删除缓存，并阻止晚到的回写重新产生记录。
4. `dsh-session-query-sqlite`：删除持久化与内存搜索索引。
5. `dsh-workspace`：取消归档、移除会话引用。

升级 DSH 时需重新核验补丁。安装依赖后重启 Host，才能使用新的生命周期方法。

## 验证

`packages/quantskills-session/tests/session-lifecycle.spec.ts` 使用真实 JSONL、JSON domain、SQLite、会话与工作区服务，在临时目录验证归档/恢复、删除、重启、子任务、独立分支保留、运行中拒绝、重复激活和中断恢复。不会删除用户会话。

`packages/ui-quantskills/tests/archived-sessions.client.spec.tsx` 覆盖四类归档列表、搜索、恢复、删除确认、失败后重试、归档与删除分流及菜单点击外部关闭。
