# 期货参考

在 QuantStudio 打开「数据库 → 期货参考」。选择交易所和品种即可查看现行最小价位、合约乘数和规则来源。目录收录截至 2026 年 11 月 23 日境内六家交易所已上市的 92 个期货品种。[中国期货业协会上市品种](https://www.cfachina.org/servicesupport/sspz/)

输入交易日查询历史行情和交易所结算参数。填写合约代码可锁定交割合约。合约代码留空时，系统按当日持仓量降序、成交量降序、合约代码升序重算收盘后的研究主力。大商所和广期所缺少本地行情归档时，使用已连接的 PandaData 主力映射和日线。郑商所使用交易所原始三位年月代码，例如 `MA509`。[PandaData 期货接口](https://www.pandaaiquant.com/docs/strategy/futures)

可填写北京时间截止点，比对源文件所标的版本更新时间。首次公布时间无原始证据时显示未知。历史板块和合约条款仅显示可核实的版本。覆盖天数来自已核验样本，单日查询以实际归档和合约为准。

| 交易所 | 交易所结算参数 |
| --- | --- |
| 上期所、上期能源、郑商所 | 按交易日读取公开归档 |
| 中金所 | 按交易日查询已发布的结算公告，源站使用 HTTP |
| 大商所、广期所 | 当前逐日结算费率尚未接入 |

手续费分开仓、平昨、平今，分别记录元/手和按成交额收取的费率。缺档时显示缺失状态。费率为交易所标准。研究使用方可将可核实的条款和费用作为回测输入。查询结果通过「数据库」和聊天共享。可在聊天里问「查询 2025-04-14 上期所 CU2505 的交易所开仓、平昨和平今费率，以及当期合约乘数」。

如已有历史参考归档，可将其放在当前 DSH profile 的 `quantskills/futures-reference/archive` 下，或在启动 QuantStudio 前设定 `QUANTSTUDIO_FUTURES_REFERENCE_ARCHIVE` 指向归档目录。其中按 `交易所/quotes`、`交易所/settlement` 和 `交易所/contracts` 保存日期文件，例如 `SHFE/settlement/20250414.json`。郑商所使用原始 `.txt`，中金所使用原始 `.csv`。大商所、广期所的授权 PandaData 日线采用 `exchange,date,contract,open_interest,volume,settlement` CSV 格式。缺少本地文件时查询相应的在线来源。
