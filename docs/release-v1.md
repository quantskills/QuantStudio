# v1 工作台更新

此分支保存本次 QuantSkills 工作台整合版本。`v1` 为 Git 分支名称，不改变上游依赖或包版本编号。

## 界面与交互

- 技能、专家、专家团各自拥有左栏入口。专家和专家团独立保存来源筛选，创建与保存后进入对应列表。
- 技能、专家和专家团图标随主题配套变化，宇宙系列使用星星、星球和星系。
- 雾蓝、青玉、暖铜三套完整深色主题增加原创 WebGL 流体光带与 Canvas 粒子；支持鼠标互动、点击涟漪、滚动联动与流星点缀。无 WebGL 时使用 Canvas 流线；动画暂停、后台标签及系统减少动态效果均停止运动。
- 右侧文件与预览栏支持折叠、全屏和分类，普通展开不会模糊、遮罩或锁定会话输入。
- 首页与会话共用内容蒙层透明度，会话蒙层仅覆盖可调宽度的内容列。
- 创作草稿集中显示最终确认，已安装技能和专家支持卸载，收藏可继续或新建对应会话。

## 工作台能力

- 模型服务配置、推理强度、权限和外观设置统一管理。
- 数据库支持 CSV/JSON、HTTP 及 PandaData 数据缓存，区分时序和非时序数据，依据新鲜度、时间覆盖和数据量决定是否命中本地缓存。
- 对话产物支持 HTML 交互预览及多媒体小窗口，并可在右侧查看文件。
- 启动默认进入 QuantSkills。用户工作区、模型凭据和研究数据继续保存在本地运行目录。

## 验证

- 完整构建、13 个包的源文件检查及 TypeScript 检查通过。
- 57 个可独立运行的测试文件，共 472 项测试通过。
- 仓库中另外三个旧团队测试套件依赖未包含的上游 `core/agent-loop/tests/mock-adapter.ts`，无法在此独立仓库加载；本次可运行测试结果不包含它们。
- 浏览器实际检查了三个极简主题、动画开关、专家与专家团导航、会话局部蒙层，以及右栏展开后的输入操作。

运行方式沿用根目录 README，安装依赖后执行 `pnpm run web`。
