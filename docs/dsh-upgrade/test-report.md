## 整个真实备份的离线核对

源为 2026-10-18 的已有一致性备份，不是运行中的数据目录。

- 17,184 个原文件逐一校验且原样保留；允许变化仅为 84 个新增 v4 会话文件。
- 所有 Profile、附件、缓存、自动任务文件、删除日志、交易数据和自建内容参与整个代际清单；JSONL 会话另核对 ID、父子关系、消息、QS 和 Team 映射。
- 两份 SQLite 数据库在另一个临时副本上执行完整性和逐表摘要，避免只读连接仍改变 WAL/SHM 文件。
- 真实旧核心解析器读取恢复代际的 84 个会话、1,223,233 条展开事件，重复读取语义一致且整个源代际不变。
- 新格式得到 11,491 条目标事件；旧版展开 chunks 与新版归并事件不是同一条数口径。允许的官方格式转换及原文映射保留，不能用事件数相等判定完整性。
- 整个候选副本先保全，旧快照才恢复到另一个目录。新增数据没有被覆盖。
- 真实副本 `runnable:false`，没有启动 Host、注册自动任务、发送团队消息或下单。

公开报告只有数量与摘要：[whole-home-proof.json](whole-home-proof.json)。原始私有明细留在本机隔离证据目录。
