# 运行时补丁处理

所有补丁由 `pnpm.patchedDependencies`、补丁文件和锁文件固定；不手改 `node_modules`。

| 原补丁/适配 | 目标处理 | 主要验收 |
| --- | --- | --- |
| Agent 生命周期 | 迁入 rc.2，保留 QS teardown 顺序与扩展；主运行逻辑使用官方 Agent | 生命周期、重复激活、并发恢复测试 |
| JSONL 会话持久化 | 使用官方句柄/租约 API；保留最小删除接口、跨进程删除标记、缓存读栅栏；删除前验证所有代际物理头部 ID | 存储生命周期、故障恢复、错误头部不删除、不写删除标记 |
| 投影缓存 | 保留按会话失效接口；使用新版投影存储 | 删除后缓存不回生、恢复中断 |
| SQLite 查询缓存 | 保留删除和失效接口 | 删除、查询和重启恢复 |
| Workspace | 保留 QS forget/归档清理所需接口，使用新版工作区服务 | 归档、恢复、共享文件保护 |
| Windows subprocess | **移除旧补丁**；使用官方 windowsHide / JobObject 行为 | Windows 原生孙进程终止测试 |
| QS Team 兼容（新增） | 官方 Team 单一服务；允许 Host 保留 childId 和 AgentOptions；显式 ID 与现有会话冲突时，在写 roster 前拒绝 | 真实官方运行时、持久化、保留 ID、恢复投递 |
| Team 工具开关（新增） | 允许 QS 关闭通用 spawn 工具，保留受限专家团激活入口 | 工具注册和团队启动测试 |
| QS 核心插件保护（新增） | 官方管理器将 QS 根包、12 个内部包及根包挂载的服务列为应用所有；禁用、卸载和实际解析名称的替换均被拒绝；Profile 事务串行、失败恢复受保护 | 真实管理器 + 独立 Profile；普通插件仍可停用。npm 别名、Git/压缩包同名核心替换和未知来源更新拒绝均已通过 |
| Node 24.0/24.1 入口兼容（新增两份） | 为 CLI 和私有子进程入口补充 `import.meta.main` 缺失时的真实路径判断；模块导入保持无副作用 | CLI 版本输出、无授权 runner 拒绝、导入无副作用、Windows/Linux 原生子孙进程回收 |

当前共十一份补丁。旧 `dsh-invariants` 不再加载，旧行为检查转为目标格式投影、持久化、生命周期和迁移测试。

四个前端 workspace 包的修改不伪装成依赖升级：旧上游、目标上游与 QS 定制分别比对，记录在 `ui-merge.json`。原生新版权限组件已接管旧 `PermissionSelect`，保留 QS 中文权限说明及显式确认测试。27 个冲突文件已逐项完成代码与回归复核，1,909 项目标上游用例通过；实际布局、子任务入口、输入及附件另做浏览器验收。jsdom 测试不冒充真实像素或硬件验证。

新增的第十一份补丁为 `@deepseek-ai/dsh-experimental-plugin-market-bundle@0.2.1-rc.2`：仅在选择官方市场 bundle 时加载固定社区目录 `dsh-plugin-catalog@2026.1020.8394`，用户自定义地址保留；不启用插件、不替换安装来源、不拥有安装操作。目录有 3,112 个条目；制品与目录摘要见 `upstream-artifacts.json`。

插件管理器补丁还包含恢复独立事务记录的公开入口。恢复只支持已知阶段，并校验原文件及安装锚点，不猜测未知状态。`ci:plugins` 对事务中断与恢复调用真实管理器，不使用单纯状态 mock。
