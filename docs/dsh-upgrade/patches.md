# 运行时补丁处理

所有补丁由 `pnpm.patchedDependencies`、补丁文件和锁文件固定；不手改 `node_modules`。

| 原补丁/适配 | 目标处理 | 主要验收 |
| --- | --- | --- |
| Agent 生命周期 | 迁入 rc.2，保留 QS teardown 顺序与扩展；主运行逻辑使用官方 Agent | 生命周期、重复激活、并发恢复测试 |
| JSONL 会话持久化 | 使用官方句柄/租约 API；保留最小删除接口、跨进程删除标记、缓存读栅栏；删除前验证所有代际物理头部 ID | 存储生命周期、故障恢复、错误头部不删除、不写删除标记 |
| 投影缓存 | 保留按会话失效接口；使用新版投影存储 | 删除后缓存不回生、恢复中断 |
| SQLite 查询缓存 | 保留删除和失效接口 | 删除、查询和重启恢复 |
| Workspace | 保留 QS forget/归档清理所需接口，使用新版工作区服务 | 归档、恢复、共享文件保护 |
| Windows subprocess | **移除旧补丁**；使用官方 windowsHide / JobObject 行为 | Windows 原生孙进程终止测试 |
| QS Team 兼容（新增） | 官方 Team 单一服务；允许 Host 保留 childId 和 AgentOptions；显式 ID 与现有会话冲突时，在写 roster 前拒绝 | 真实官方运行时、持久化、保留 ID、恢复投递 |
| Team 工具开关（新增） | 允许 QS 关闭通用 spawn 工具，保留受限专家团激活入口 | 工具注册和团队启动测试 |

当前共七份补丁。旧 `dsh-invariants` 不再加载，旧行为检查转为目标格式投影、持久化、生命周期和迁移测试。

四个前端 workspace 包的修改不伪装成依赖升级：旧上游、目标上游与 QS 定制分别比对，记录在 `ui-merge.json`。原生新版权限组件已接管旧 `PermissionSelect`，保留 QS 中文权限说明及显式确认测试。27 个原冲突文件仍需要逐项视觉复核，不能仅凭类型检查标记全部验收。
