## 已实现

- 根项目及 12 个 workspace 包固定目标核心和兼容声明；锁文件、上游 tarball 完整性、生成接口和构建产物一起更新。
- 新版应用自有 Profile 加载；安装指纹包含核心、锁文件和插件清单；失败安装保留原 Profile 和失败候选。
- 启动器协议 2：不可变版本目录、校验后原子切换、安装互斥；未知状态拒绝恢复猜测；候选必须完成独立迁移检查和父子 IPC 握手。
- 握手校验 nonce、QS 提交、实际核心、数据代际、制品摘要、迁移状态及必要服务。另做 HTTP 入口检查；HTTP 不能替代握手。
- 官方 Team 服务成为唯一运行时。旧 QS 包保留适配导出、离线历史分类和显式恢复；旧运行时源码移除。
- 旧会话 v0–v3 → v4 的离线转换，完整 Zstd 帧读取、QS 元数据保留、Team v1 → v2、原文件/ID 映射/独立日志、互斥和幂等验证。
- “旧团队消息”只在用户查看时核对，在用户明确继续时恢复。接收方已持久化但回执未写入时不重发；不确定状态保留待确认。
- 四个定制 UI 包迁入目标上游代码和接口；保留 QS 工作台、附件、审批入口、专家团、执行过程等定制。实际浏览器验证范围见测试报告。
- 新版持久化删除、缓存失效和 Windows 原生子进程行为专项回归；插件来源从实际 manifest/lock/install 取证，阻止迁移时替换来源。
- `pnpm run ci:plugins` 在无凭据临时 Profile 中使用本机 registry、压缩包和 Git 仓库，调用真实官方管理器验证五类来源的安装/更新、npm 别名、失败回滚、并发及卸载。
- `preserveAndRestoreCopy` 离线保全候选全目录，再把旧快照恢复到另一目录；未知或变化的代际、输出篡改及并发操作拒绝，不自动激活。

## 合并阻塞项

这些是未完成的验收或实现，不能用基础构建通过代替：

1. **插件管理迁移尚未完成**：旧市场仍挂载，官方管理器尚未成为所有修改操作的唯一入口。已接入官方管理器入口，并保护 QS 根包及 12 个内部包的启停、卸载和已知名称替换；五类来源已通过隔离的真实官方管理器安装/更新、失败回滚与并发验收；Git/压缩包同名核心替换仍需完成；来源不明项的只读约束还需贯穿所有运行时修改入口。已关闭旧市场自行重启。浏览器实测确认旧 `dshmarket 1.45.1` 被上游版本兼容检查拦截，保留其配置和挂载声明，没有授予不兼容豁免。
2. **完整数据代际激活尚未完成**：离线会话转换已验证，但它不是整个用户数据目录的可运行证书。尚需统一迁移 Profile、缓存、附件、自动任务、删除恢复日志和交易数据，完成当前一致性快照及所有语义对账，再接入正式候选激活。
3. **启动器过渡和实际回退**：协议故障测试、候选原生启动、新启动器运行真实旧核心已在 Windows/macOS/Linux 通过；已新增离线全目录回退工具并完成构造样本演练：先保全候选全部数据，再恢复旧快照到独立目录，包含 SQLite 完整性及新增成交核对。真实数据的完整核心兼容验证和激活仍未完成。
4. **前端及功能清单**：三方差异已合并并通过类型/构建/单元测试，但 27 个定制冲突文件的逐项视觉复核、所有新增能力的成功/失败/重启测试尚未全部完成。
5. **平台及外部条件**：Windows 本地原生测试和 Windows/macOS/Linux Node 22.19.0 完整 CI 已通过；Node 24.0.0 的启动失败已定位为缺失 `import.meta.main`，最小入口补丁通过 Windows 原生验证及 Linux 完整 CI。macOS 浏览器、账号登录、SSH、语音设备和外部服务仍需对应测试条件，不能算通过。
