# JEV 多品种盯盘

在「比赛 → JEV 盯盘 → 设置」搜索或按交易所筛选，勾选多个品种。每个品种读取比赛柜台当前主力合约，也可选择候选月份或手填实际合约。候选月份需经过柜台核验；目录中的品种不等于每个月份都可交易。新增品种没有本地 tick 参数时，须补齐参数。

各合约共用策略文字、每个合约的持仓手数上限、整个运行的开仓计划总上限、账户权益停止线、执行方式与开仓冷却。价格相关阈值按各品种 tick 换算。自动历史行情分别创建或复用各合约数据源；手动数据源按实际合约过滤，不混用其他品种的 K 线。

Host 轮询全部所选合约，各自保留快照、历史缓存、决策间隔和分析记录。单个合约缺行情不阻塞其他合约。模型分析期间继续采集当前合约，分析完成后继续轮询；配置的决策间隔是每个合约的最短间隔，实际频率受品种数、模型耗时和比赛接口额度影响。账户巡检和交易额度继续全局共享，不为每个品种另开高频账户轮询。

逐笔确认模式仍需确认计划；自动模式的启动确认会列出全部实际合约。存在未确认计划、活动委托或未核实回执时沿用账户等待规则；所有品种共用开仓计划数量上限。停止一次即停止整个运行；重启保留配置和分析记录，不自动恢复盯盘或重新提交旧决策。

验证覆盖：批量勾选与主力查询、搜索保留选择、取消恢复草稿、全部合约校验、不同品种快照与 tick 隔离、缺行情品种不阻塞其他品种、跨品种计划及共享开仓上限、停止与重启。交易链路测试使用隔离的模拟柜台，不向真实账户提交测试委托。
