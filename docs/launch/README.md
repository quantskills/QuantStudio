## 公众号发布

1. 在公众号后台先上传完整宣传片，放在正文开头。
2. 复制 HTML 中的正文排版，或按 Markdown 继续修改。
3. 将图片上传至公众号素材库，替换本地路径或无法载入的外链。
4. 手机预览后由发布者发布。原生视频、封面与图片上传不能通过粘贴 HTML 自动完成。

独立发布包提供带可播放视频的 HTML 预览、纯正文 HTML、Markdown、PNG 原图与配乐/无声 MP4。仓库 HTML 不引用本机视频绝对路径，避免其他读者打开时出现失效播放器。
