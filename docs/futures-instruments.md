# 期货品种适配

QuantStudio 的 Jev 盯盘按实际合约运行。客户端提供六家境内期货交易所的品种选择，服务端不以预设品种列表限制盯盘；自定义合约也走同一套行情、历史、持仓、预演与人工确认流程。

当日目录含 90 个启用条目及 1 个未启用条目（LR 晚籼稻）。这是柜台元数据快照，不是所有条目已实盘验证的声明。启用状态以最新同步结果为准。

连接比赛账户时，客户端通过现有比赛查询接口调用 `panda varieties --json`；要求 CLI ≥ 0.1.23。目录同步不会请求行情、调用 Jev 或创建交易。可在比赛页检查更新 CLI。同步失败、取消或返回无效目录时保留已有目录；新目录不会覆盖正在编辑的合约参数。

实时目录可以新增品种而不改代码。新条目若没有本地 tick，界面会要求填写。未知品种也可手动指定交易所与 tick；不会默认套用另一个品种的参数。

## 合约格式

- 输入实际交割合约，不输入品种简称或连续合约。例如 `m2701`、`MA701`、`IF2612`、`sc2611`、`lc2611`。
- 郑商所三位月份代码原样保留，不自动改成四位月份。
- 大商所月均价目录代码是 `L_F / V_F / PP_F`，实际合约形如 `l2610F / v2610F / pp2610F`。历史、持仓、预演和成交匹配保留后缀，不能与 `l2610 / v2610 / pp2610` 混用。
- PandaData 历史请求使用大写、带交易所后缀的代码，例如 `MA701.CZC`、`L2610F.DCE`。这种格式转换不替换品种、月份或交易所。
- 同一品种改 tick 可保留手动历史映射；换合约或交易所清除旧映射。按键输入中间状态不会把自定义交易所和 tick 重置。

## 最小价格变动来源

柜台 varieties 协议返回代码、名称、交易所及启用状态，**不返回 tick**。代码中的 tick 是可编辑参考值，不能称为实时合约参数查询。核对材料：

1. [PandaAI 官方执行规范](https://www.pandaaiquant.com/openapi/v1/meta/agent-spec)：目录、解析接口及 CLI 最低版本。
2. [上期所品种细则](https://www.shfe.com.cn/regulation/exchangerules/productrules/)：各品种最小变动；本地值包含 AU 0.02、BU 1 等。
3. [中金所 2 年期国债合约](http://www.cffex.com.cn/2ts/)及同站其他品种合约：TS 0.002，TF/T 0.005，TL 0.01，股指 0.2。
4. [广期所合约资料接口](http://www.gfex.com.cn/u/interfacesWebTtQueryContractInfo/loadList?variety=&trade_type=0)：SI 5、LC 20、PS 5、PT/PD 0.05。
5. [郑商所菜籽油细则](https://www.czce.com.cn/cn/uploadfile/2024/02/07/20240207144928864.pdf)、[PTA 细则](https://www.czce.com.cn/cn/uploadfile/2024/11/19/20241119163530748.pdf)。
6. [华金期货合约简表（2026-05-19）](http://www.huajinqh.com/UserFiles/upload/file/20260518/华金期货交易品种合约简表20260519.pdf)：其余品种交叉核对材料；与较新交易所公告冲突时使用公告值。
7. [豆油、棕榈油最小变动调整通知转载](https://futures.cmschina.com/main/a/20260402/15796.shtml)：按大商所通知，自 2026-04-10 起 Y/P 最小变动为 1，覆盖旧简表中的 2。

维护目录时应记录核对日期和来源，不根据其他品种推测未知 tick。修改 tick 后，模板的 tick 单位阈值保持不变，价格价差按对应 tick 比例调整。

## 行情与交易边界

“已在目录中”与“可以采样、生成计划”不同：实际交割月份须有效，比赛柜台须返回该合约的新鲜报价；PandaData 历史覆盖和授权单独检查。仅授权 PandaData 不会自动使比赛柜台的即时行情就绪。未启用、过期、无报价或缺少历史的具体合约应展示诊断信息，不能以其他合约的数据补位。

此适配覆盖六家境内交易所的期货接口；不宣称期权、组合合约或境外交易所已接入。

回归使用模拟账户、行情与执行响应，覆盖全部 91 个目录条目的盯盘配置、三种模板、六交易所历史路由、月均价预演与成交隔离、目录同步与失败回退。测试不下单、不调用 Jev、不证明所有合约都具备外部行情权限。


## 果蝇与 Jev 共用品种目录

- `contest-products.ts` 是前端与宿主共用的目录；Python 控制器随包携带相同的 `futures-products.json`，一致性测试防止两端漂移。目录不是白名单，未来新品种可以手动填写实际合约和交易所。
- 果蝇支持六个国内期货交易所的目录搜索、交易所筛选与手动添加。原先前端、Zod、Pydantic 的 7 品种限制已移除；保留每品种一个实际合约、重复校验、账户绑定与逐笔确认。
- 月均价品种使用 `l_f / v_f / pp_f` 标识，实际合约保留 `F` 后缀。主力简称解析不适用于月均价时要求手动填入实际合约，不能降级为普通品种。
- Python 交易时段区分股指、国债、有夜盘商品与日盘商品；未识别新品种保留数据源原始 K 线，不推测休市缺口。节假日与最后交易日仍依靠真实行情新鲜度和柜台校验。
- 时段核对：[上期所交易时间](https://www.shfe.cn/services/calenderandholidays/tradinghours/)、[中金所国债合约](https://www.cffex.com.cn/30tl/)、[郑商所瓶片交易规则](https://www.czce.com.cn/cn/uploadfile/2024/08/30/20240830162542437.pdf)。目录中未启用的品种仍需柜台实际开放后才能参赛交易。
