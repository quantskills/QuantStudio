# 标准回测假设（人类锁定，agent 不可改）

任何严肃回测都要把这些假设**写在文档里**，不能藏在代码里。

## A 股截面多头回测（推荐 baseline）

| 项 | 标准设定 | 含义 |
|---|---|---|
| **选股** | 每日按 signal 截面排名取 Top 10% | 多头组合 |
| **入场** | T+1 开盘 | 用 T 日收盘后的信号，T+1 早盘买入 |
| **出场** | T+1+H 开盘 | H 日后的早盘卖出 |
| **持仓** | 等权（Top N 资金均分） | 不做风险预算 / 因子加权 |
| **重叠** | 每日 1/H 资金被换仓 | 滚动持仓，避免一次性大换手 |
| **不可买** | `trade_status==1`（停牌）或 `close >= limit_up*0.99`（涨停） | A 股特有 |
| **不可卖** | `trade_status==1` 或 `close <= limit_down*1.01` | A 股特有 |
| **手续费** | 双边 15 bp（佣金 + 印花 + 滑点综合估计） | 现实拟合 |
| **资金** | 假设无限大、无市场冲击 | 中频策略足够，超低延迟不适用 |

> 参考实现：`auto_research_alpha/evaluation.md §7` + `prepare.backtest()`。

## 跨市场调整

### 美股

| 项 | 调整 |
|---|---|
| 涨跌停 | 没有，改用 `gap_open > 5%` 等代理 |
| trade_status | 改用 `volume == 0` 判停 |
| 手续费 | 双边可降到 5bp（量大时更低） |
| T+0 | 美股允许，但研究阶段建议保持 T+1 假设以贴近 IB 等券商默认 |

### 期货

| 项 | 调整 |
|---|---|
| 持仓 | 改成单合约 Long/Short，不是 Top 篮子 |
| 涨跌停 | 各品种不同，按交易所规则 |
| 手续费 | 按品种 / tick size 算 |
| 主力换月 | 必须处理（roll cost） |

## 这些假设的"价值"

不是"实盘交易的真理"，是"研究阶段的标准"。实盘还要加：

- T+1 涨停打开后的成交假设
- 大单市场冲击模型
- 券池融券限制
- 集合竞价 vs 连续竞价的成交价差

研究阶段把这些假设**全部锁死**，不同因子才能横向比较。

## 反模式

- ❌ 在某个因子的回测里偷偷把手续费降到 5bp："让数字好看一点"
- ❌ 假设可以 T+0："反正信号变化快"
- ❌ 不剔涨跌停："数据里就是这样"
- ❌ 用全市场而非动态成分池："反正是回测"

每一条都让回测**结果失真**，让因子不可比。
