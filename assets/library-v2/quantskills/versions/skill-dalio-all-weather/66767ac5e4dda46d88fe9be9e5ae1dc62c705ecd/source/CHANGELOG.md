# Changelog

## [0.5.0] - 2026-08-05

- 新增 `health-check`，启动前检查 Python、SDK、DNS、TLS 握手、证书、主机名和凭证配置。
- 真实数据命令改为检查或登录失败即停止，不能再绕过安全会话继续访问数据。
- HTTPS 端点必须由 PandaData 数据服务方提供并维护；不再接受旧环境变量的静默回退。
- 地址禁止内嵌凭证、查询参数和片段；健康检查与错误输出不显示秘密信息。
- 支持并分别验收 Python 3.11 与 3.12，持续集成同步覆盖两个版本。

## [0.4.0] - 2026-07-18

### Security

- PandaData 地址必须使用受信 HTTPS；未加密 HTTP 和所有 HTTP 重定向均被拒绝。
- 数据客户端强制校验证书，并只携带进程内令牌，不保存账号密码。
- 在整个命令进程内禁止第三方库读取、写入、自动刷新或删除 `user.json`。
- 令牌到期后不从磁盘自动登录，必须重新启动命令并重新认证。

### Corrected

- 当前配置和宏观诊断 CSV 均带 `RESEARCH_ONLY` 标记。
- GitHub Actions 固定到已知提交，并关闭检出凭证持久化。
- 社区元数据改为有条件验证，明确真实运行所需的外部 HTTPS 服务与权限。

## [0.3.1] - 2026-07-18

### Corrected

- 残缺的首季度不再在数据首日生成初始目标。
- 最后一个季度必须由自然季末或后续季度数据确认，不再按“距季末不超过 7 天”推断。

### Added

- 所有未命中缓存的 PandaData 分段请求最多重试 3 次，并使用短指数退避。
- 回测新增 `decision_dates.csv` 和 `target_weights.csv`，可独立核验决策日、下一共同交易日和目标权重。
- 安装元数据与发布环境统一限定为 Python 3.12。
- 增加 QUANTSKILLS 社区清单、公开使用说明和数据授权边界。

### Safety

- 同名结果目录存在时校验参数、数据和源码指纹；不一致时拒绝覆盖。
- 重试日志不包含凭证或查询参数。
- 包版本、报告版本和发布版本保持一致，并由回归测试校验。

## [0.3.0] - 2026-07-17

### Corrected

- 季度计划日只在完整季度的最后交易日产生；季中截止不会伪造季度调仓。
- 目标在下一交易日执行。回测维护真实持仓漂移，不再每日免费恢复目标权重。
- 季度目标即使数值未变，也会在下一交易日按漂移持仓计算真实 L1 换手。
- 换手门槛和成本改为比较执行前实际持仓；输出实际执行日期和逐日换手。
- 默认象限切换只记录、等季度日再采用；即时切换调仓改为显式可选开关。
- 基金和期货收益优先使用 `close/pre_close`，缺字段才退到连续收盘差分。
- 期货代码增加交易所后缀；无效债券指数替换为经验证的 `000012.SH` 广义国债替代。
- CPI 和 GDP 分别使用 15 日、30 日公布滞后。

### Added

- 五类核心资产强制完整，单类最低覆盖率 80%，并记录覆盖率。
- 回测起点前 400 个自然日预热，分开记录请求、数据和实际评估日期。
- 反波动率方法明确命名，不宣称严格 ERC；新增 60 日协方差风险贡献和集中度诊断。
- 参数化 `run_id` 输出目录，避免不同起点、成本、窗口和开关互相覆盖。
- 数据与源码 SHA-256、Skill 版本、63/60/20 宏观参数、收益口径和成本口径完整写入报告。
- IR 诊断必须显式指定单个 symbol，禁止无 symbol 全库查询。
- 报告顶部增加 `RESEARCH_ONLY` 与不可直接实盘声明。
- 补充针对已修复问题的回归测试。

### Safety

- 拒绝负成本、负换手门槛和非正窗口。
- 第三方失败只记录异常类型，不回显完整异常或凭证。
- 自动测试完全离线，不读取用户级凭证文件。
