# A 股全天候研究方法

> RESEARCH_ONLY：本文描述研究模型，不构成投资建议或实盘许可。

## 1. 增长 × 通胀

模型把宏观状态分成四类：

| | 通胀上行 | 通胀下行 |
|---|---|---|
| 增长上行 | Q1：过热 | Q2：复苏 |
| 增长下行 | Q3：滞胀 | Q4：衰退 |

本实现不预测宏观绝对水平，而是识别方向变化：

1. CPI 同比和 GDP 同比分别与 63 个交易日前比较。
2. 原始方向在过去 60 个交易日做多数平滑。
3. 新方向连续满足 20 个交易日后才通过磁滞切换。

诊断文件保留原值、63 日变化、原始方向、平滑方向、磁滞方向和最终象限。

## 2. 公布滞后与修订值

接口只有 `period_date`，没有每次发布的真实 `release_date`，因此使用：

- CPI：报告期后 15 个自然日；
- GDP：报告期后 30 个自然日。

该规则避免直接在报告期末使用尚未公布的数据，但供应商展示的历史值可能已经修订。没有 point-in-time vintage 时，任何延迟近似都不能消除修订值前视。

## 3. 反波动率风险预算

默认五类基准为股票 30%、长债 40%、中债 15%、黄金 7.5%、商品 7.5%，并按象限调整偏好。目标日使用 t-1 及以前的 60 个交易日：

```text
target_i = normalize(quadrant_base_i / volatility_i)
```

这是一种带基准偏好的反波动率风险预算，不是严格 ERC。真正的协方差风险贡献为：

```text
RC_i = w_i * (Σw)_i / (w'Σw)
```

系统用 60 日协方差报告 `RC_i`、最大绝对贡献和 HHI 集中度，但不利用该诊断反向优化目标。风险贡献高度集中时只发出警示。

## 4. 目标日、执行日和持仓漂移

默认只在完整季度的最后共同交易日形成新目标。残缺的首季度不形成初始目标；最后一个季度只有在查询窗口已到达自然季末，或已经观察到下一季度交易日时才确认。系统不会把“距离自然季末不超过若干天”当作季度完成证据。季度中途象限变化会被记录，但要到下一个季度目标日才采用最新象限。可选开关允许象限切换日额外形成目标，默认关闭。

目标日 t 使用的信息只到 t-1，目标最早在下一交易日执行。回测按以下顺序运行：

1. 交易日前保留上一日收盘后漂移的实际持仓权重。
2. 如果前一交易日形成了目标，以实际持仓到目标的 L1 距离计算换手。
3. 仅当真实换手达到门槛时执行；执行日扣除 `L1 换手 × cost_bps`。
4. 用当日各资产简单收益更新资产价值和组合净值。
5. 由更新后的资产价值重新计算下一日实际持仓权重。

因此，目标不变并不意味着季度末没有交易；如果持仓已漂移，仍会按真实差额回归目标。非执行日不会免费恢复目标权重。

## 5. 预热与评估边界

60 日波动、63 日宏观变化、60 日平滑和 20 日磁滞都需要请求起点之前的数据。CLI 向前扩 400 个自然日：

```text
data_start = requested_start - 400 calendar days
```

完整区间用于信号、目标和持仓状态模拟；绩效、换手和执行日只从 `requested_start` 之后的首个共同交易日开始。元数据分别记录请求起点、预热数据起点和实际评估起点。

## 6. 行情收益口径

若返回含 `close` 和 `pre_close`：

```text
r_t = log(close_t / pre_close_t)
```

这优先于连续收盘差分，可减少基金分红除权和期货主连换月跳变被误当成收益。只有没有 `pre_close` 字段时才使用：

```text
r_t = log(close_t) - log(close_{t-1})
```

实际回退链和每段收益口径写入结果。该方法仍不能替代严格复权、合约展期和可交易价格研究。

## 7. 五类资产和覆盖率

股票、长债、中债、黄金、商品缺一不可。系统先在并集日历上检查每类覆盖率不低于 80%，再保留五类共同有收益的日期。缺失核心资产或覆盖不足会明确失败，而不是把缺失收益填成零。

长债和中债的指数兜底都使用经验证可返回数据的 `000012.SH`。它是广义国债指数，不能解释为精确 10 年或 5 年久期。ETF 和交易所后缀期货仍是区分久期的主要候选。

## 8. 复现记录

每个研究产物至少记录：

- 运行参数和 `run_id`；
- 请求、预热和实际交易日期；
- 63/60/20 宏观参数和 CPI/GDP 分项滞后；
- 五类覆盖率、实际回退链和收益口径；
- 数据 SHA-256 和源码 SHA-256；
- Skill、Python、pandas、numpy 和 panda_data 版本；
- 目标决策日、实际执行日、真实持仓、真实换手及成本口径；
- 协方差风险贡献和集中度。

`decision_dates.csv` 给出决策日和样本内下一共同交易日；`target_weights.csv` 给出逐个决策日的五类目标权重。样本末日之后的执行日不在已知数据内，因此保持空白，不做推测。相同参数目录再次运行时，只有数据和源码指纹一致才允许复写；不同指纹会明确拒绝。
