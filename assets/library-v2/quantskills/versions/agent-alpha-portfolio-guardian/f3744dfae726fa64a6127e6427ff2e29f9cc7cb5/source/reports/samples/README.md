由 `python -m runtime self-test` 刷新。

- `mock_run/` — 四件套研究态样例
- `backtest_mock/` — 守卫信号有效性回测样例

`mock_run` 关键文件：`runtime_report.md`、`health_matrix.csv`、`crowding_alerts.json`、`retire_rebuild_candidates.csv`、`ic_decay_curves.json`、`agent_snapshot.json`、`trade_calendar.json`。

`backtest_mock` 关键文件：`l4.html`（浏览器打开）、`backtest_report.md`、`bucket_stats.csv`、`accuracy.json`、`rolling_oos.csv`、`summary.json`。
