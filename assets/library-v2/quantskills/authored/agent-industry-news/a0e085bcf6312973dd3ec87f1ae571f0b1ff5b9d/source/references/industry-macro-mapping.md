# 行业-宏观数据映射参考

本文档记录了 skill-macro-monitor 中与地产、医药、新能源三行业相关的主要数据方法。

---

## 🏠 地产行业

| 方法 | 说明 | 参考 |
|------|------|------|
| `get_macro_detail` | 搜索/确认指标代码 | 所有行业通用 |
| `get_macro_rc` | 房地产链相关数据 | 地产核心方法 |
| `get_macro_re` | 房地产 | 行业高频指标 |
| `get_macro_mb` | 货币/信贷（房贷利率相关） | LPR、社融等 |
| `get_macro_ir` | 利率（房贷利率） | 5年期LPR等 |
| `get_macro_ci` | 居民消费/收入 | 购房能力相关 |
| `get_macro_cm` | 建筑材料 | 水泥、玻璃等 |

### 常用指标方向
- 商品房销售面积/金额
- 新开工面积
- 房地产开发投资完成额
- 土地购置面积
- 房贷利率（5年期LPR）
- 居民中长期贷款
- 建材价格（螺纹钢、水泥、玻璃）

---

## 💊 医药行业

| 方法 | 说明 | 参考 |
|------|------|------|
| `get_macro_detail` | 搜索/确认指标代码 | 通用 |
| `get_macro_ph` | 医药相关数据 | 医药核心方法 |
| `get_macro_pr` | 价格指数 | PPI（医药制造） |
| `get_macro_in` | 工业数据 | 医药制造业增加值 |
| `get_macro_ci` | 居民消费 | 医疗保健支出 |
| `get_macro_fe` | 财政支出 | 医疗卫生财政支出 |

### 常用指标方向
- 医药制造业增加值
- 医药制造业PPI
- 医疗卫生财政支出
- 居民医疗保健消费
- 药品集中采购中标数据（需财经新闻补充）
- 创新药审批信息（需新闻补充）

## ☀️ 新能源行业

| 方法 | 说明 | 参考 |
|------|------|------|
| `get_macro_detail` | 搜索/确认指标代码 | 通用 |
| `get_macro_en` | 能源数据 | 新能源核心方法 |
| `get_macro_ee` | 电力设备 | 光伏/风电装机 |
| `get_macro_au` | 汽车 | 新能源汽车产销 |
| `get_macro_me` | 有色金属 | 碳酸锂、钴等 |
| `get_macro_ch` | 化工 | 隔膜、电解液等上游 |
| `get_macro_te` | 进出口 | 光伏/锂电出口 |
| `get_macro_ep` | 环保 | 碳中和政策相关 |

### 常用指标方向
- 光伏新增装机容量
- 风电新增装机容量
- 新能源汽车产量/销量
- 动力电池装车量
- 碳酸锂/多晶硅价格
- 光伏组件出口数据
- 锂电池出口数据

---

## 📋 通用查找流程

1. 对每个行业，先调用 `get_macro_detail` 搜索候选指标
2. 确认指标代码、频率、单位、更新时间
3. 选择合适方法调用获取数据
4. 将数据与新闻内容交叉验证

### 交叉验证标注规则

| 标注 | 条件 |
|------|------|
| 确认 | 新闻所述趋势与最新宏观数据方向一致 |
| 矛盾 | 新闻所述趋势与最新宏观数据方向相反 |
| 数据不足 | 无对应宏观数据、数据过时、或无法确定方向 |
