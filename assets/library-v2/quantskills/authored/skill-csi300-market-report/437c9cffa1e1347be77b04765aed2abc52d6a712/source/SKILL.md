# 沪深300市场日报/周报（CSI 300 Market Report）

## 核心规则

- 使用 PandaData MCP 工具（`mcp__pandadata__*`）获取所有数据。如果当前 Session 没有 MCP 工具，可以运行 `scripts/market_report.py` 作为备选方案。
- 沪深300指数代码为 **`000300.SH`**。成分股列表通过 `get_index_weights` 获取最新的前 50~300 只权重股。
- 默认覆盖全沪深300成分股，回看窗口不超过 1 年。重点关注用户指定的板块或个股。
- 所有数据标注来源方法、参数和最新数据期。计算值（如涨跌幅、贡献度）必须标注为 `计算值`。
- 默认输出中文 Markdown 报告。除非用户明确要求 HTML/交互式产物。

## 前置检查

1. **PandaData 登录验证**：调用 `mcp__pandadata__auth_status`，确认 `reauth_required` 为 false。如需要重新登录，请用户打开 QuantSkills Settings → PandaData 点击 Login。
2. **确认日期**：如果用户未指定日期，用当天日期调用接口；如果返回空数据，向前回退到上一个交易日（跳过周末及节假日）。
3. **方法可用性检查**：先查询需要的方法文档，确认参数和返回字段。

## 数据获取流程

### 步骤 1：指数行情概览

| 方法 | 参数 | 用途 |
|------|------|------|
| `get_index_daily` | `symbol="000300.SH"`, `start_date`, `end_date` | 指数日线：开盘价、收盘价、最高价、最低价、成交量、成交额 |
| `get_index_indicator` | `symbol="000300.SH"`, `start_date`, `end_date` | 指数估值：PE(TTM)、PB(LF) |

日报：取指定交易日当天的单日数据。周报：取该周 5 个交易日的数据，计算周涨跌幅和周均成交额。

### 步骤 2：成分股权重与行业分布

| 方法 | 参数 | 用途 |
|------|------|------|
| `get_index_weights` | `index_symbol="000300.SH"`, `start_date`, `end_date` | 成分股权重（至少取权重前 50） |
| `get_stock_detail` | `symbol=<成分股代码列表>` | 获取成分股名称、板块 |
| `get_stock_industry` | `stock_symbol=<成分股代码>` | 获取申万一级行业分类（L1） |

日报：取最新一个交易日的权重快照。周报：取该周最后一个交易日的权重快照。

对权重前 50（或全部，视返回行数配额而定）的成分股，逐只调用 `get_stock_industry` 获取行业归属。按申万一级行业（L1）汇总统计。

### 步骤 3：行业板块表现

将步骤 2 得到的行业归属与指数日线数据交叉：

- 每个成分股相对于前收盘的涨跌幅
- 按行业汇总：行业涨跌家数、平均涨跌幅、行业权重占比、行业贡献度（权重 × 涨跌幅 / 100）
- 排序展示：涨幅前 5 行业、跌幅前 5 行业

### 步骤 4：成分股 TOP 榜单

- **涨幅 TOP 10**：当日/当周涨幅最大的 10 只成分股（含行业归属）
- **跌幅 TOP 10**：当日/当周跌幅最大的 10 只成分股
- **权重贡献 TOP 5**：对指数涨跌点数贡献最大的 5 只成分股（权重 × 涨跌幅估算）
- （可选）用户关注个股的独立分析

### 步骤 5：近期走势回顾

获取过去 5/20/60 个交易日的指数日线数据：

- 近 5 日涨跌幅（周度视角）
- 近 20 日涨跌幅（月度视角）
- 近 60 日涨跌幅（季度视角）
- 对应周期的最大回撤
- 对应周期的日均成交额变化

### 步骤 6：市场广度指标（日报特有）

- 成分股上涨 / 下跌 / 平盘家数
- 上涨占比（%）
- 成交额较前一日变化率
- 成交额较近 20 日均值变化率

## 备选脚本

如果 Session 环境缺少 MCP PandaData 工具，可以运行 Python 备选脚本：

```bash
python scripts/market_report.py --date YYYYMMDD --mode daily --out-dir output/
```

脚本依赖：
- Python 3.10+
- `panda_data` 包（PandaData SDK）
- `pandas`

查看脚本详细文档：`scripts/market_report.py --help`

## 失败处理

| 场景 | 处理方式 |
|------|---------|
| 指定日期无数据（非交易日） | 自动向前回退到最近交易日，并告知用户实际使用的日期 |
| 成分股权重未返回完整 300 只 | 使用返回的部分数据，标注实际使用的成分股数量 |
| get_stock_industry 配额不足 | 只分析权重前 20 的行业归属，其余标注"未获取" |
| PandaData 登录失效 | 提示用户重新登录：QuantSkills Settings → PandaData → Login |
| 所有数据接口均失败 | 给出错误诊断，建议稍后重试或检查网络 |
