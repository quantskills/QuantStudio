# @deepseek-ai/dsh-client-ui-quantskills

[English](README.md) | 中文

共享输入框的加号启动器包含“文件”“QuantSkills”和“常用”。“文件”会打开当前 Session 已挂载的隐藏原生文件输入，继续复用现有 Host 上传与持久引用流程，不建立第二条附件路径。空白 Session 会在 Hero 预设选择器旁通过紧凑的 PandaAI 标识、滑动开关、连接操作和红黄绿 Host 状态灯提供既有 PandaData MCP Remote；对话开始后，同一控件会移动到输入框工具行。PandaData 登录不会成为普通 Session 创建的前置条件。

QuantSkills 配色会在 QuantSkills 会话可见期间接管原生会话输入框表面并隐藏原生“预览版”徽标。关闭插件后，DSH 显示会恢复。

客户端会在自身生命周期内替换 stock document favicon 与 Web App manifest，使浏览器应用窗口和任务栏使用 QuantSkills 标志，而不是 DSH 图标。

创建普通 Session 时，界面会立即进入会话中心，并在 Workspace 解析与 Host 创建期间显示禁用的进度操作。创建完成后只执行一次共享打开协调，不再预先刷新全部 QuantSkills 存档或重复收养同一 Session。

QuantSkills 面向两种明确 DSH 组合的应用 UI。在保留的独立版组合包中，本包拥有根框架，提供保留的 conversation 插件所需的 `ctx.layout` 面板操作，并声明标准 `sidebar`、`conversation`、`details`、`shell.overlay` slot 和 `quantskills.page` 座位。在原生插件组合包中，原生外壳已经声明 `shell.overlay`；本包因此通过 `sidebar.footer.action` 添加入口，并通过该 overlay 添加全屏工作台，不会替换原生布局、侧边栏、工作区浏览、设置、会话或详情所有者。打开绑定 Session 时，工作台保持挂载为 QuantSkills 导航、常驻且可调整宽度的会话存档切换栏和原生 DSH conversation。Overlay 会独占左侧组合栏，使原生 Sidebar 保持挂载但被隐藏并设为 inert，同时把原生 conversation 重排到剩余空间。收起存档切换器时，独占宽度会更新为 QuantSkills 导航宽度，绝不会露出原生 Session 列表；释放声明后会恢复用户未改变的原生 Sidebar 偏好。选择另一条存档只会切换原生 Session；若 Host 持有的存档尚未进入当前 Client 投影，插件会先完成协调再选择，并丢弃已被后续点击替代的晚到结果。点击“会话”返回插件存档首页，只有“返回主界面”会关闭工作台。两种组合使用同一套 controller、Host 状态、页面和 Session 操作。QuantSkills 品牌只出现在 QuantSkills 自己拥有的界面：插件入口与工作台导航使用用户提供的方形标识，宽应用标题栏把 QuantSkills 横版标识与次级 PandaAI 背书组合显示；原生外壳继续显示自己的侧边栏标识和产品名称。QuantSkills 工作台显示对话时，嵌套的 identity 与轮次状态 slot 会改用 QuantSkills 标识和产品文案；关闭工作台后恢复原生空会话身份与活动标签。独立版在自己拥有的会话中始终使用 QuantSkills 身份。可见文案用中性名称描述周边运行时，原生包 id 与兼容性文档继续保留准确技术名称。

Skills 页面只通过可信 QuantSkills Host Remote 读取动态分类和已批准资产。页面以 Host 解析的中文名作为主标题，以不变的仓库资产 id 作为次要技术信息。匹配精确版本的已安装声明含有中文一级标题时，它会覆盖目录生成名；保存在 `ui-quantskills` 设置 namespace 的本机名称又可以覆盖前两者，但不会改变安装、更新、搜索或 Session 绑定身份。搜索同时索引当前中文名、Host 中文名与英文名、别名、摘要、说明和精确资产 id。目录行保留简短中文摘要；打开详情时，Client 会请求 Host 读取该资产已批准精确 commit 的仓库根 `README.md`，并渲染完整 Markdown。成功的 README 响应会按资产 id 和 commit 缓存到本次 Client 生命周期；详情请求失败时会回退到中文摘要，不会阻止安装或使用。同一个解析结果还用于常用技能、最近会话、会话切换器、Agent 精确版本编排和 Agent 市场；用户创建的 Agent 始终保留所有者填写的名称。Client 启动时会执行一次必需的目录读取。Host 报告目录事件流已连接时，Client 会消费 Host 发布的已校验快照，并停止焦点与定时间隔的回退请求；断开后会恢复这些持久自动检查，Host 公布的默认间隔为五分钟。新的检查会取消已被取代的 Remote 请求，插件销毁会取消全部活动目录操作，请求 revision 仍会阻止晚到响应覆盖更新投影。每次安装请求都会带上用户当时看到的目录 snapshot id 与精确 commit；Host 会在发布不可变版本前拒绝陈旧观察。已安装状态只来自 Host 已提交版本列表；浏览器不直接请求 GitHub，也不缓存、伪造或持久化安装事实。Host 不可用或投影陈旧时，界面会如实显示并禁用受影响操作。

如果已安装的是旧 commit，Skills 列表与抽屉会把获批 commit 标为可用更新，并且仍要求用户明确点击后才安装。更新会发布另一个不可变版本；现有已绑定 Session 继续解析日志记录的版本，从目录新建的 Session 才使用当前已安装 commit。首页输入框会把完整任务、此前的导购追问与回答，以及当前获批 Skill 元数据的有界投影发送给临时的模型目录导购 Session。宽泛或信息不足的需求会得到一个针对性问题和二至四个可选回答；信息充分的需求会得到一至三个按适合程度排序的精确目录候选及对应理由，或者一段说明为何更适合创建新 Skill 的自然解释。Client 会用同一份可信快照校验模型返回的每个资产 id、归档辅助 Session，并继续要求用户明确确认后才安装。用户确认后才会按需安装精确版本、创建独立绑定 Session 并发送累积后的任务上下文；创建流程也会把同一上下文交给 AI Skill 创作助手。首页还会从同一份 Host 快照派生当前公开资产总数、Skill 和 Agent 总数，以及每个分类的总数和 Skill／Agent 分项。选择分类会在首页原位筛选包含目录 Agent 的精选榜单；每个条目都可以安装或更新获批版本，并且只有 Host 确认当前版本后才会切换为对应的使用或创建副本操作。明确的“查看全部”操作会把仅含 Agent 的分类带到 Agent 市场并保留分类筛选，其他分类则进入 Skills 页面。Skills 筛选栏不会显示没有 Skill 的分类，Agent 市场拥有自己的带数量分类筛选。更新设置会区分自动目录检查、无人值守安装 Skill 和替换 DSH bundle；本包的后台工作不会执行后两项。

Panda 设置通过类型化 Host Remote 检查活动的私有 Python 与 PandaData 环境，普通插件页面不会触发软件安装。启动会恢复活动环境并执行一次官方版本检查，但不会在后台激活更新；安装、验证更新、修复和回滚仍需要用户明确操作，首次启动 QuantSkills Session 时则会自动准备兼容的托管运行时，再打开登录。运行环境页显示 Python 来源与版本、活动与官方最新 SDK、可回滚版本、API 指纹，以及互相独立的鉴权、有界读取和执行就绪状态。“已连接”只能证明凭据重放通过鉴权；只有 Host 报告活动环境已成功完成有界读取和执行探针后，QuantSkills 任务才能开始。执行状态还会显示可信 sandbox 后端及其实际 `full` 或 `partial` 隔离级别。Windows ACL 就绪状态显示为“可执行 · Windows 兼容隔离”，不会冒充 `full`；macOS Seatbelt 与 Linux bwrap 或 Landlock 显示各自报告的级别。后端缺失或失败时，状态为不可用并阻止任务，不会提供未隔离的备用执行。只有首次替换激活成功后才会显示可回滚版本；在此之前，界面会说明当前没有回滚版本。首次准备必须先通过固定兼容矩阵、wheel 摘要、导入和 API 指纹检查才会激活；之后的明确登录还必须完成鉴权、有界只读数据验证和执行探针，QuantSkills 任务才能开始。每个带凭据的更新、修复或回滚候选都会安装到新的不可变环境，并且只有通过相同检查后，Host 才会切换激活指针。候选失败不会改变活动环境或登录，会删除它的未提交目录，并显示 Host 返回的精确且可安全展示的失败类别，而不是泛化的候选校验失败。在对应操作成功前，该失败会在环境检查、版本检查和浏览器刷新之后继续显示。任何运行时检查进行中，所有受影响操作都会禁用，使用明显不可用的外观和对应状态文案，不会继续呈现为可点击状态。明确登录成功后，Host 会在操作系统 Keyring 可用时保存标准化账号和密码；Host 启动、窗口重新获得焦点、网络恢复和每个 QuantSkills 预检都会在新 worker 中重放凭据。Keyring 不可用时登录只在当前运行期有效，界面会明确提示重启后需要重新登录。鉴权拒绝会进入重新认证状态，网络错误不会删除已保存凭据。表单明确区分手机号、邮箱和用户名：`+86` 仅是手机号的可编辑默认区号，邮箱和用户名不拼接区号。密码只用于写入请求，每次尝试后都会从表单清除，不写入 DSH 设置、Session、浏览器存储或 PandaData `user.json`。每个登录与执行 worker 都会在退出前清理 SDK 鉴权残留。退出登录会删除 Keyring 条目和内存凭据，并验证 SDK 残留已清理。每个 QuantSkills Session 都会冻结精确运行时绑定，并通过 `quantskills_panda_python` 执行脚本；更新活动环境不会改变既有 Session 的绑定，原生 DSH Session 保持不变。

活动、并行和存档视图只读取 Host Remote 提供的权威 Skill 绑定、Agent 与 Agent Team Lead Session 投影，普通 DSH Session 和 Team 成员 child Session 不会出现在这些视图中；常用 Skill 行仍然只从真实的单 Skill 存档派生。统一会话中心会在普通 Session 与 QuantSkills Session 中始终挂载。它的切换器把 Skill、Agent 与 Agent Team 分为三个标签页，在选中类型内搜索中文名和技术 id，并把全部存档归入本地的“最近1小时”“今天”“昨天”“最近7天”或“历史”。选择有存档的类型时，界面会在需要时打开该类型的最新存档；选择空类型时会显示该类型自己的空状态，不会继续露出另一类型的会话正文。浏览器本地通知投影会先把既有历史设为基线，之后只把新的完成或失败运行状态变更记为未读。铃铛、会话导航角标和受支持的系统应用角标显示相同的未读数；打开对应的精确结果 Session 后，该项会变为已读。并行控制会对运行中、等待中、失败、已取消和最近完成的工作分组；等待状态只根据当前运行时交互快照叠加，回复抽屉会打开该精确 Session。继续某个存档会直接打开其既有 Session id。会话中心的“新对话”始终分配不带常驻 Skill、Agent 或 Agent Team 绑定的全新普通 DSH Session；技能、智能体与 Agent Team 页面中的上下文操作则为明确选中的不可变投影分配全新 Session。在原生插件组合中，普通、Skill、Agent、Agent Team、创作、角色辅助和测试入口都会在创建前调用同一个 Workspace 解析器，并明确传入其返回的 `workspaceId`。首选已注册 Workspace 可用时，解析器使用可选的 `defaultWorkspaceId` 设置；否则延迟创建或重新注册由 Host 托管的 QuantSkills Workspace。失效的自定义选择会被清除，自动回退到托管 Workspace，并显示一次非阻塞通知。只有 Host 故障导致两个目标都不可用时，界面才会打开运行环境设置的修复视图。原生插件不会继承当前 Session、最近 Workspace、浏览器路径或 DSH 进程工作目录。独立版继续使用当前 Workspace 选择，不会创建托管 Documents 目录。Workspace 解析成功后，界面会在打开新 id 前让共享 Session 运行时完成协调；绑定创建还会核验完整投影，缺失、取消或投影不匹配都会保留此前选中的 Session。新 Skill 会话会打开空白输入框，而它的精确基础 Skill 已经常驻于 Host 持有的模型上下文中；界面不会插入合成的用户指令。同一 Skill、用户 Agent 或 Agent Team 的多个存档保持独立并可直接切换。每一行都可以通过标准 Session 接口重命名底层会话；Host 接受的标题会持久保存在 Session 日志中，成功后会刷新三类存档投影，运行中的会话也可以重命名。切换器宽度可以本地调整，分隔条可完全隐藏存档抽屉，导航边缘会保留恢复入口。会话管理只作用于当前可见类型，可以全选空闲行、删除明确选择的会话，或经确认后清空全部空闲行。批处理逐个通过 Workspace 归档权威提交 Session，并只刷新一次三类存档投影；如果中途失败，已完成的归档仍会先同步到界面再显示错误。运行中的会话不能被选中删除，并且会在清空时保留。单个和批量确认框都会说明原始记录仍保留在 DSH 归档中。移除当前空闲会话后会打开下一个最近的 QuantSkills 保留会话；没有保留会话时创建一个全新普通 Session，因此删除操作绝不会把用户带到第二套存档页面。

共享输入框的加号启动器包含“QuantSkills”和“常用”入口。“QuantSkills”会按 Host 分类体系从分类进入可选子分类，再列出 Skill 与 Agent；选择 Skill 时会按需安装获批精确版本，并在当前 Session 中切换其加载状态，选择 Agent 则会打开独立且不可变的 Agent Session。“常用”会列出按真实绑定会话频次统计的 Skill，以及确实存在存档的用户 Agent。`quantSkillsResidentSkills` 投影会在输入框中渲染一个紧凑的已加载能力控件。向上菜单会列出当前精确常驻集合，允许逐个移除 Skill，并打开目录选择器添加能力；这些操作不会修改草稿或增加会话消息。Agent 身份固定显示在菜单中，因为 Agent 配置仍由其已保存定义和独立 Session 持有。目标组合至少暴露一份有效 `qsh-form` 时，同一菜单会增加“参数”，并向上打开参数抽屉。抽屉可在符合条件的 Skill 或 Agent 来源之间切换，展示任务、声明字段、默认值、固定选项与真实 Session 附件，并提供“填入输入框”和“应用并运行”。两个操作都会要求 Host 校验并渲染纯文本；前者只替换草稿，后者通过普通提示词队列提交。自然语言对话仍是默认界面。无效表单会标记为“参数不可用”用于诊断，但不会禁用该能力。通过确定性旧格式适配器的表单会标记为“已兼容旧格式”，参数抽屉同时说明原始能力文件未被修改。

Agents 页面把获批 Agent 市场、直接对话启动器和真实 Host 编辑器组合在一起，而不是使用浏览器示例。每个已保存 Agent 都是一键对话入口：存在存档时继续最近会话，否则创建第一次会话；独立的“新对话”操作始终创建新的 Session。只有创建 Agent 或点击齿轮设置时才显示配置，取消会返回启动器且不修改 Host 定义。安装市场 Agent 会递归安装从经过校验的 `AGENTS.md` 解析出的依赖，导入一份可编辑定义且选中已保存编辑器，不会把 Agent 注册为 Skill。用户必须填写名称和角色、选择编排方式与权限，也可以选填精确 Skill 组合、模型和推理强度；每个字段都会标识必填或选填状态，无效输入会保留在对应字段旁。零 Skill 定义是角色型 Agent。手动 Agent Team 编排器会让 Lead 和每个成员明确选择模型策略：跟随 Session 默认模型，或为该角色冻结提供方、模型与可选推理强度。不同角色可以使用不同模型，原有的统一权限要求保持显示并继续校验。创建、更新和删除都会刷新 Host 投影，乐观 revision 会阻止覆盖更新的定义。启动或隔离测试未保存的 Agent 会先校验并保存，因此主要的保存并启动操作不会运行草稿。随后它会从已保存 revision 创建一个独立 Agent Session，应用已保存的模型和权限，只有 reconcile 核验其不可变 Agent 投影后才打开 stock conversation。界面不会在本地保存定义、伪造执行进度，也不会把多 Skill Agent 改写成单 Skill 存档。

会话中心的标题栏始终显示一个 AI 创作菜单，包括普通状态和空状态。菜单渲染在 document overlay 中，因此可调整大小的存档抽屉无法裁剪它。创建 Skill、Agent 或 Agent Team 时会调用专用 Host 创作 Session 接口；该接口在打开新的 workspace-write Agent Session 时原子追加带精确类型的 `quantskills/authoring-started`。Host 根据持久事件注册创作工具，不再依赖 Agent 显示名称。Skill 与 Agent 创作只会写入 `quantskills-drafts/`；`quantskills_asset_draft` 使用安装器安全规则验证完整目录树，解析精确依赖和运行要求，并返回规范化 `treeDigest`。Agent Team 创作会逐轮询问三个阶段：目标与交付、Lead 与成员职责，以及必须确认的模型策略。模型策略可让全部角色跟随 Session 默认模型，也可为每个角色分别选择提供方、模型和推理强度。完成这些阶段后才使用 `quantskills_team_draft` 准备精确 Agent revision、显式角色模型选择与诊断。成功 Tool Result 是可恢复的草案权威，不重复写入草案事件。确认卡片会显示每个角色的模型策略，打开手动编排时也会保留这些选择。确认卡片调用 `authoringCommit(sessionId, toolCallId, expectedTreeDigest)`；Host 会证明成功 Tool Result 属于该 Session 和类型，重新读取并校验草案，执行幂等乐观提交，并追加唯一的 `quantskills/authoring-committed`。Skill 与 Agent 提交会在 `$DSH_HOME/quantskills/authored/` 发布带 `origin: local-authoring` 的不可变本地 Git 快照，与官方目录版本分离，也不会修改或推送 QuantSkills 仓库。Team 提交使用相同的确认与冷恢复路径，再按用户选择启动。智能体页仍提供 AI 创建与手动配置或编排两条明确路径，并在禁用保存操作旁解释未满足的前置条件。

通过 stock composer 提交的提示词仍调用已绑定的 Session face，使普通的持久化提示流程保持权威。QuantSkills 不会从通用运行时 Session 名册或浏览器存储推导存档和使用频次事实。查看筛选器、排序与面板选择仍属于浏览器本地 UI 状态，不替代持久 Session Event。Host 的 `ui-quantskills` 设置 namespace 持有可选的 `defaultWorkspaceId`、界面与会话比例、自动目录检查、Panda 预检与恢复策略、收藏，以及新建 Agent 的提供方、模型、推理强度和权限默认值。缺少 `defaultWorkspaceId` 表示使用托管 QuantSkills Workspace。运行环境设置会显示该托管路径，允许从已注册 DSH Workspace 中选择一个替代项，并提供恢复默认操作，不暴露 Workspace 模式，也不会在每次创建时提问。在 Host 报告设置可写之前，设置控件保持不可用；Host 接受的值可由另一个浏览器读取。

stock composer 只在 Skill 与 Agent Session 中增加 QuantSkills 文件控件。浏览器对每个所选文件读取一次，把规范 base64 发送给 `fileAttach`，并且只把 Host 返回的持久附件 id、文件名与解析状态追加到草稿。UTF-8 文本、PDF、受支持 Office 文档和电子表格的限制、存储、Session 归属与解析分类都由 Host 持有；不支持或失败的文件保持明确状态，浏览器不会插入猜测内容。用户提交草稿后，模型通过作用域 `quantskills_read_attachment` 工具读取成功提取的有界文本。

独立版保留自己的框架比例和现有三栏视觉基线。原生插件版则让插件自有界面直接继承 DSH 的字体、颜色、边框、间距、阴影和动效 token。14、13 和 12 三个语义文字层级来自 DSH token，而不是插件全局基础字号，因此默认密度与周围原生外壳一致。可选的 60–150% 界面缩放会对插件自有页面、Session 切换器和结果渲染器分别应用一次带尺寸补偿的变换，让文字、控件、卡片、间距与布局尺寸整体变化而不留下空白；插件页眉与导航尺寸使用同一个比例。缩放后的切换器会把指针移动量换算回已保存的逻辑宽度，Host 的独占左栏声明则接收缩放后的物理宽度。会话文字比例使用另一条临时插件声明：只有在插件内打开 QuantSkills 存档时，stock conversation 的正文列才会读取该基础字号；退出插件、返回存档列表或关闭该会话都会释放声明，并立即恢复 DSH 原值。该声明不会写入 document 样式或 DSH 外观设置，也不会改变页眉、输入框尺寸和其他 Session 的显示。会话切换器宽度属于浏览器本地展示状态：分隔线支持指针拖拽、方向键、Home、End 和双击复位；其控件可以完全隐藏抽屉，并在导航边缘留下恢复标签。结果分隔条提供相同的直接隐藏操作，窄布局则会同时隐藏切换器与分隔线。Skill 详情和 Panda 登录面板在桌面固定布局中是带标签的 region，在抽屉断点以下转为模态 dialog；Escape 可关闭，并把焦点恢复到打开面板的控件。每个 Skill 行以独立的键盘可访问详情按钮承载查看操作，与安装或启动操作分开。

紧凑导航栏还会在“设置”正上方声明并渲染标准 `sidebar.footer.action` 列表。附件清理等可选扩展因此保持可见，同时不会成为本包的依赖。

QuantSkills 产品拥有的普通会话、已绑定 Skill、用户 Agent、Agent Team Lead 或 Agent Team 成员 Session 会在 stock 会话标题旁获得可叠加的“结果”操作。只有 Host QuantSkills 投影精确标识当前 Session 时才会出现该操作；原生 DSH Session 不渲染 QuantSkills 结果界面。保留的独立版会把 `quantskills.results` slot 呈现为响应式抽屉；原生插件版会在工作台打开期间通过 `ctx.layout.claimDetails()` 独占完整 DSH 详情栏。stock DetailsPanel 继续挂载，但会被隐藏、设为 inert、不可聚焦且不可交互，因此不会再露出第二条狭窄栏。列宽求解器只约束一次请求宽度；打开会重排 stock 会话栏，拖动会更新独占声明并关闭过渡动效，关闭则释放声明并恢复原生详情状态和宽度。用户明确打开原生 Tool 详情时，会先让出并关闭结果工作台，再由原生面板接管。全高分隔线支持指针和触控拖动，也支持方向键、Home、End 和双击复位，并把宽度保存在浏览器本地视图状态。切换到没有对应选中产物的 Session 时，工作台会关闭。产物导航优先展示 Assistant 行内代码中明确交付的精确可预览路径，再加入当前已加载 Conversation 窗口中 `ui-deliverables` 记录的成功变更位置。Client 会在显示前把每个候选路径发送给 `quantSkillsSessions.resultPrepare`；普通可用文件使用 Host 返回的规范 Session 工作区路径，经授权的旧 Skill 产物或持久日志证明成功写入的会话外产物复制到 `output/quantskills/` 后会标记为“已归档”，其他不可用候选不会进入产物导航。已准备文件会按规范工作区路径去重，因此重复历史引用会消失，而不同目录下的真实同名文件仍会保留。Client 绝不会把已安装版本源码路径或其他外部路径直接发送给预览；`resultPreview` 仍会在该 Session Workspace 内解析并校验每个已准备路径。用户产物写入其 `output/`，创作草稿写入 `quantskills-drafts/`；已安装版本中的输出在 `resultPrepare` 归档获授权旧文件之前保持不可读。运行中、已完成和失败活动来自同一 Session 折叠后的 Tool 生命周期。产物工作台在集合变化时自动选择价值最高的交付文件，并保留多个可关闭的文件标签：Markdown 使用共享富文本渲染器，代码使用共享高亮器，HTML 在禁用脚本与网络的沙箱中运行，表格使用可搜索的 CSV／TSV 网格，受支持的 Office 文档使用有界提取文本阅读模式，通过校验的图片和 PDF 使用内嵌查看器。“产物”“概览”和“运行”保持为独立标签，选择任意文件都会回到它的完整预览。只有当前所选运行从运行中变为完成，并且结束 Turn 记录了至少一个内置预览可渲染的结构化变更路径时，结果工作台才会自动打开一次；Assistant 路径提及、纯文本回复、只有 Tool 活动的运行、不支持的二进制文件、初始已完成历史、后台 Session，以及完成后被用户手动关闭的结果工作台都不会打开或重开。自动打开不会抢占输入焦点；只有明确点击产物链接时，焦点才会移动到预览标题。用户仍可明确点击“结果”或行内产物路径手动打开。其他操作会打开产物所在目录，或创建一个独立后续会话并在草稿中引用来源 Session 和所选路径。Assistant 正文只贡献显式行内代码文件候选，不会提供结果值、图表、Tool 活动或隐含的自然语言文件名。

打开工作台时还会调用 Host `resultList`，从完整持久 Session 日志重建并校验文件归属。Client 会把按最新引用排序的结果与当前窗口候选合并，因此实时输出仍会及时出现，而重启、冷恢复或尚未加载的旧分页不会再隐藏历史产物。运行活动与已加载轮次计数仍然只描述当前窗口。

结果工作台顶部只保留“产物”“概览”“运行”和关闭操作，不再重复显示会话标题或能力身份。所选产物预览会占满工作台的全部剩余高度。HTML 与 PDF 内嵌框架填满该区域，并在框架内部滚动完整文档；Markdown、表格、代码与提取文本也保留各自完整的可滚动阅读面。文件操作显示为“在 IDE 中打开”；Host 仍会校验所选工作区路径，再把它交给已配置的桌面打开能力。

全部运行中 Session 会保留在所选 Skill、Agent 或 Agent Team 历史标签上方的一个全局分组中，因此活动工作不会被类型筛选隐藏。只有空闲存档使用所选类型的时间分组与批量操作。左侧存档分隔条和右侧结果分隔条在抽屉关闭后都会留下边缘恢复控件。

## 模型体验

### Session 提示词

#### 模型看到的内容

通过现有 `Session.prompt` face 提交的用户输入提示词原文。Host 持有的常驻投影中的每个 Skill 都会通过作用域 literal 系统提示词区段提供其精确声明；加载或卸载都不会伪造用户消息。未保存的 Agent 草稿不会进入模型请求；Host 创建 Agent Session 后，已记录的角色、编排方式和当前精确常驻 Skill 内容会成为作用域 literal 系统提示词区段。目录浏览、导航、筛选、Panda 表单草稿、应用偏好和尚未提交的参数值不会进入模型请求。应用参数表单会通过同一提示词 face 产生普通用户文本。提交后的通用文件草稿只包含持久引用与明确解析状态；模型读取文件时，附件工具结果才会加入受支持文本。

#### Token 影响

用户提示词产生的可变 token 会保留在该 Session 的历史中，直到压缩。常驻 Skill 与 Agent 角色会增加由 Host 持有的系统提示词前缀 token；本 Client 包不独立添加提示词段或工具 schema。

#### KV Cache 影响

常驻集合稳定时，它会形成可复用的请求前缀，而每条新用户消息保持仅追加。加载或卸载 Skill 会改变下一次请求的前缀，并可能使变更区段之后的缓存条目失效。

## 已知限制与延期事项

- 自动目录检查绝不会安装可执行源码。无人值守安装 Skill 需要先为普通未绑定 consumer 建立版本策略，DSH bundle 升级仍由安装与重启流程负责。
- 结果工作台只覆盖当前已加载的 Conversation 窗口。没有结构化变更位置的终端命令只有在 Assistant 消息使用行内代码明确点名完整工作区相对路径时才会进入导航；更早的文件只会在对应历史页加载后出现。
- 内联预览有意限制为 Host 读取的文本、提取出的 Office 文本、沙箱化 HTML、通过校验的图片与通过校验的 PDF。它不提供 Office 原始版式还原、OCR、嵌入附件提取或活动 HTML 内容。金融指标与图表仍需要权威产物或领域投影，绝不会从 Assistant 文本合成。
- 目录 Agent 会连同精确的已安装 Skill 依赖导入为可编辑定义；它们不会成为 Skill 注册表条目，之后的目录变化也不会改写已导入定义。
- 每个 profile 只能通过一个 QuantSkills 组合包装配本包：独立组合包替换 stock 根布局和侧边栏，原生插件组合包则保留两者并使用它们的叠加扩展位。
