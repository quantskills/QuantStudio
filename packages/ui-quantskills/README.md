## Model Experience

### Session prompt

#### What the model sees

The exact user-entered prompt submitted through the existing `Session.prompt` face. Each Skill in the Host-owned resident projection contributes its exact declaration through a scoped literal system-prompt section; loading or unloading one never fabricates a user message. An unsaved Agent draft never enters a model request; after the Host creates an Agent Session, the logged role, orchestration mode, and current exact resident Skill contents become scoped literal system-prompt sections. Catalog browsing, navigation, filters, Panda form drafts, application preferences, and unsubmitted parameter values never enter a model request. Applying a parameter form produces ordinary user text through the same prompt face. A submitted generic-file draft contains only the durable reference and explicit parsing state; the attachment Tool result adds supported text only when the model reads it.

#### Token effect

The user prompt's data-dependent tokens remain in that Session's history until compaction. Resident Skills and Agent roles add Host-owned system-prompt prefix tokens; this Client package adds no independent prompt section or tool schema.

#### KV Cache effect

A stable resident set remains a reusable request prefix and each new user message is append-only. Loading or unloading a Skill changes that prefix for the next request and can invalidate cache entries after the changed section.

## Known Limitations and Deferred Work

- Automatic catalog checks never install executable source. Unattended Skill installation needs a version policy for ordinary unbound consumers, and DSH bundle upgrades remain owned by the installation and restart workflow.
- The result workbench covers only the current loaded Conversation window. Terminal commands that create files without a structured mutation location enter the navigator only when an Assistant message explicitly names the complete workspace-relative path in inline code; older files appear only after their history page loads.
- Inline preview is intentionally bounded to Host-read text, extracted Office text, sandboxed HTML, verified images, and verified PDFs. It does not provide Office layout fidelity, OCR, embedded attachment extraction, or active HTML content. Finance metrics and charts still require an authoritative artifact or domain projection and are never synthesized from Assistant prose.
- Catalog Agents import as editable definitions with exact installed Skill dependencies; they do not become Skill registry entries, and later catalog changes do not rewrite imported definitions.
- Each profile composes this package through exactly one QuantSkills bundle: the standalone bundle replaces the stock root layout and sidebar, while the native-plugin bundle keeps both and uses their additive extension seats.
